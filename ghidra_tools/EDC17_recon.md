# EDC17CV44 — разведка под поиск экологии
Файл: TC1767_1037549567P949V791 (old ECU), 2 MB дамп флеша TC1767
ASAM id: `50/1/EDC17CV44_5_C3/0/P_949//P_949_7_9_1_FF_SCR///`  @ 0x8007DE78
=> Коммерческий EDC17 **CV44**, ПО **P_949_7_9_1**, конфигурация **FULL_SCR** (система AdBlue/SCR).

## Карта памяти (по энтропии блоков, база 0x80000000)
| Адрес | Содержимое |
|-------|-----------|
| 0x80000000–0x80027FFF | boot, вектора, ранний код + данные |
| 0x80028000–0x8003FFFF | пусто |
| **0x80040000–0x8009FFFF** | **КАЛИБРОВКИ / карты** (здесь карты EGR/SCR/NOx) |
| **0x800A0000–0x8018FFFF** | **основной КОД** (логика управления) |
| 0x80190000–0x801FFFFF | пусто |

## Кандидаты осей карт экологии (uint16 LE)
Температурные (°C, окно выхлопа/SCR/катализатора):
- 0x80041604, 0x80041abe : [0,8,70,90,110,130,170,210,250,300]
- 0x8004af0e            : [0,25,50,...,375]
NOx / концентрация / ppm-диапазон:
- 0x80041cca / 0x80041d6e / 0x80041e12 : [0,250,500,...,1750]
- 0x80042828 / 0x80042838             : [0,290,570,...,2000]
- 0x80042f80                          : [0,8,820,880,920,...,1200]
- кластер 0x80046e5c..0x800479xx      : [0,125,...,1875] и [0,250,...,1750] (много карт подряд -> вероятный NOx/SCR блок)
Общие оси двигателя (для привязки):
- RPM: 0x8004023e [800,1600,1800,...,3800], 0x80041448 [500,1000,...,7000]
- нагрузка/топливо: 0x800404d6 [0,1000,...,13000]

## Как довести до конкретных функций (в вашей Ghidra)
1. Запустить ghidra_tools/FindCalibRefs.py (Script Manager) — построит
   отчёты map->функции и "плотность калибровок по функциям" в /tmp.
2. Прыгнуть на адрес кандидата-оси (G -> адрес), встать на начало карты,
   References -> Show References to -> перейти в читающую функцию.
3. В функции смотреть: что сравнивается с порогами, какие входы (датчики NOx,
   температуры, дифдавление), какие выходы (дозатор, клапан EGR).

Примечание: оси сами по себе не доказывают назначение карты — общие оси
встречаются в разных подсистемах. Окончательная привязка — по коду функции.
